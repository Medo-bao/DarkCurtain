# 暗黑天幕 - 息屏保护

Windows 托盘小工具：一键息屏，屏幕变黑，但电脑不会进入待机，后台任务和外部设备继续正常运行。

息屏采用纯黑全屏遮罩，以解决部分电脑息屏影响电脑运行的问题。



## 使用

1. 双击 `暗黑天幕.exe` 启动，会显示主控制窗口；关闭窗口只是隐藏到托盘，不会退出。
2. 点“开始息屏”或按 `Ctrl+Alt+B` 息屏；再按一次或点“解除息屏”恢复。
3. 右键托盘图标可立即息屏、打开设置或退出。
4. 设置里可选择“启动时最小化到托盘”“开机时自动启动”等行为。
5. 设置页的“定时关机”可选择 1 至 1440 分钟，点击“开始计时”立即生效；再次设置会替换原计划，“取消关机”可撤销计划。

定时关机仅在设置页显示和管理，隐藏到托盘后继续计时。默认使用软件计时，退出软件会取消计划，到期执行 `shutdown /s /t 0`，不强制关闭应用。电脑休眠期间不会被本软件唤醒。

开启“定时关机采用 Windows 命令”后，开始计时会立即执行 `shutdown /s /t N`（N 为分钟数乘以 60），退出软件后仍生效。正数倒计时会隐含强制关闭应用，请提前保存工作。“取消关机”执行 `shutdown /a`，重新计时先取消再提交。开关切换不改动已有计划，需重新计时后生效。再次打开软件会显示保存的 Windows 计划时间，但无法实时检测其他软件对该计划的修改。

息屏期间程序会保持系统不休眠。开启“关闭显示器电源”后只发送关屏指令，不创建黑幕、不隐藏鼠标、不调整亮度，也不会定时重复关屏；再次按 `Ctrl+Alt+B` 或退出软件会发送唤醒指令。
