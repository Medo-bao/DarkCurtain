# 暗黑天幕 - 息屏保护

Windows 托盘小工具：一键息屏，屏幕变黑，但电脑不会进入待机，后台任务和外部设备继续正常运行。

息屏采用纯黑全屏遮罩，默认不关闭显示器电源，避免显卡/USB 供电变化影响电机等外接设备。
息屏期间鼠标指针也会隐藏，解除后自动恢复。
息屏时会把屏幕亮度压到最低，退出息屏后自动恢复原亮度。

## 使用

1. 双击 `暗黑天幕.exe` 启动，会显示主控制窗口；关闭窗口只是隐藏到托盘，不会退出。
2. 点“开始息屏”或按 `Ctrl+Alt+B` 息屏；再按一次或点“解除息屏”恢复。
3. 右键托盘图标可立即息屏、打开设置或退出。
4. 设置里可选择“启动时最小化到托盘”“开机时自动启动”等行为。
5. 设置页的“定时关机”可选择 1 至 1440 分钟，点击“开始计时”立即生效；再次设置会替换原计划，“取消关机”可撤销计划。
6. 设置窗口会记忆上次关闭时的位置，下次打开自动恢复。

定时关机仅在设置页显示和管理，隐藏到托盘后继续计时；退出软件会取消计划，重启不会恢复旧计划。请提前保存工作，关机不强制关闭应用，未保存的文档可能阻止关机。电脑休眠期间不会被本软件唤醒；恢复运行时若已到期，会发出关机请求。

息屏期间程序会保持系统不休眠。设置里可勾选“同时关闭显示器电源”。

## 构建

```powershell
dotnet publish -c Release -r win-x64
```

发布文件会输出到项目根目录的 `release` 文件夹。
