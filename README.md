# 暗黑天幕 - 息屏保护

Windows 托盘小工具：一键息屏，屏幕变黑，但电脑不会进入待机，后台任务和外部设备继续正常运行。

默认息屏采用纯黑全屏遮罩，不关闭显示器电源；隐藏鼠标指针并尝试降低亮度，解除后恢复。
开启“关闭显示器电源”后，只向 Windows 发送关屏指令，不创建黑幕、不隐藏鼠标、不调整亮度。再次按 `Ctrl+Alt+B` 会发送唤醒指令；退出软件也会唤醒显示器。该模式不再定时重复关屏，普通输入可能按 Windows 的行为唤醒显示器。

## 使用

1. 双击 `暗黑天幕.exe` 启动，会显示主控制窗口；关闭窗口只是隐藏到托盘，不会退出。
2. 点“开始息屏”或按 `Ctrl+Alt+B` 息屏；再按一次或点“解除息屏”恢复。
3. 右键托盘图标（盾牌）可立即息屏、清理内存、打开设置或退出。
4. 设置里可选择“启动时最小化到托盘”“开机时自动启动”等行为。
5. 设置页的“定时关机”可选择 1 至 1440 分钟，点击“开始计时”立即生效；再次设置会替换原计划，“取消关机”可撤销计划。
6. 设置窗口会记忆上次关闭时的位置，下次打开自动恢复。
7. 点击主窗口设置左侧的清理图标，或托盘右键菜单中的“清理内存”，会立即执行设置中选定的清理项。清理过程中可继续操作息屏和定时关机。

## 内存清理

提供待机列表、系统文件缓存、低优先级待机列表、进程工作集、修改页列表、注册表缓存和内存合并七项手动清理，与 NexBox 的手动清理项目对应。默认勾选前四项；设置页可调整并保存选择，也可直接清理当前所选项。

系统缓存操作会在需要时弹出 Windows 管理员授权，由同一个程序启动一次清理任务，完成后退出。仅选择进程工作集时不要求管理员授权；无法访问的进程会跳过。工作集整理会跳过软件自身、系统关键进程和已识别的游戏进程。

结果显示整轮清理前后的可用内存变化和各清理项结果。进程工作集减少量单独统计，不能直接当作物理内存释放量。清理失败或部分失败会如实显示，不会以清理自身内存冒充系统缓存清理成功。内存清理完全由手动触发。

退出软件或清理等待超时时，会通知管理员清理任务停止剩余操作。设置保存或开机自启登记失败会显示具体原因；无法读取原背光亮度时，会跳过背光调暗，避免无法恢复原亮度。

## 定时关机

定时关机仅在设置页显示和管理，隐藏到托盘后继续计时。默认采用软件计时，退出软件会取消计划，重启不会恢复旧计划；到期执行 `shutdown /s /t 0`，不强制关闭应用，未保存的文档可能阻止关机。电脑休眠期间不会被本软件唤醒。

勾选“定时关机采用 Windows 命令”后，点击“开始计时”会立即执行 `shutdown /s /t N`，其中 N 为分钟数乘以 60。Windows 接管倒计时，退出软件后仍有效；软件再次启动会显示保存的计划时间，但无法实时检测其他软件对系统计划的修改。Windows 的正数倒计时隐含强制关闭应用，请提前保存工作。“取消关机”执行 `shutdown /a`，会取消当前系统关机计划；“重新计时”先取消旧计划，再提交新计划。切换开关不改动已有计划，需重新计时才应用新模式；“保存设置”会记住开关选项。

息屏期间程序会保持系统不休眠。设置里可勾选“关闭显示器电源”。
